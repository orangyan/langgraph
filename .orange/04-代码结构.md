## 核心文件详解

### `libs/langgraph/langgraph/graph/state.py`

**StateGraph**: 用户面向的图构建 API

```python
class StateGraph(Graph):
    def add_node(self, node: str, action: RunnableLike) -> None
    def add_edge(self, start_key: str, end_key: str) -> None
    def add_conditional_edges(
        self,
        source: str,
        path: RunnableLike,
        path_map: Optional[dict] = None,
    ) -> None
    def compile(
        self,
        checkpointer: Optional[BaseCheckpointSaver] = None,
        interrupt_before: Optional[list[str]] = None,
        interrupt_after: Optional[list[str]] = None,
        context_schema: Optional[type] = None,
    ) -> CompiledStateGraph
```

**编译过程**: `StateGraph.compile()` → 验证图结构 → 构建 Channel 映射 → 创建 `CompiledStateGraph`（继承 `Pregel`）

### `libs/langgraph/langgraph/pregel/main.py`

**Pregel**: 执行引擎（CompiledStateGraph 的父类）

```python
class Pregel(Runnable[Input, Output]):
    nodes: dict[str, PregelNode]     # 节点映射
    channels: dict[str, BaseChannel] # Channel 映射
    checkpointer: BaseCheckpointSaver | None

    def invoke(self, input: Input, config: Config = None) -> Output
    async def ainvoke(self, input: Input, config: Config = None) -> Output
    def stream(self, input: Input, config: Config = None, *, stream_mode) -> Iterator
    async def astream(self, input: Input, config: Config = None, *, stream_mode) -> AsyncIterator
    def get_state(self, config: Config) -> StateSnapshot
    def update_state(self, config: Config, values: dict) -> Config
```

### `libs/langgraph/langgraph/pregel/_loop.py`

**PregelLoop**: 超步循环的核心

```python
class PregelLoop:
    def tick(self) -> bool:
        """
        执行一个超步：
        1. 从 Channels 读取当前状态
        2. 确定哪些节点有新输入（通过 Channel 版本比较）
        3. 检查 interrupt_before 中断点
        4. 构建 PregelTask 列表（包含节点名、输入、配置）
        5. 返回 True 如果有任务要执行
        """
```

### `libs/langgraph/langgraph/prebuilt/tool_node.py`

**ToolNode**: 工具执行节点

```python
class ToolNode(RunnableLike):
    """并行执行所有工具调用"""
    def __init__(self, tools: list[BaseTool])

    def __call__(self, state: dict) -> dict:
        messages = state["messages"]
        last_message = messages[-1]
        # 并行执行 last_message.tool_calls
        results = asyncio.gather(*[
            self._run_tool(tool_call)
            for tool_call in last_message.tool_calls
        ])
        return {"messages": [ToolMessage(...) for r in results]}
```

**`ToolCallWrapper`**: 包装单个工具调用，支持重试和错误处理

### `libs/checkpoint/langgraph/checkpoint/base/__init__.py`

**Checkpoint 数据结构**:

```python
@dataclass
class Checkpoint:
    v: int                            # 格式版本（当前为 1）
    id: str                           # UUID
    ts: str                           # ISO 时间戳
    pending_sends: list[SendProtocol] # 待处理的 Send() 调用
    versions_seen: dict[str, dict]    # 每个节点已处理的 Channel 版本

@dataclass
class CheckpointMetadata:
    source: str           # "input" | "loop" | "update"
    step: int             # 超步编号（-1 = 初始化，0+ = 执行）
    writes: dict          # 这次 checkpoint 写入了什么
    parents: dict         # 父 checkpoint（用于子图）
```

## 关键依赖关系

```
StateGraph.compile()
    ↓ 创建
CompiledStateGraph (继承 Pregel)
    ↓ .invoke() 调用
SyncPregelLoop
    ↓ .tick() 循环
PregelTask（节点执行请求）
    ↓ 执行
节点函数 (用户代码)
    ↓ 返回
Channel.update()（状态更新）
    ↓ 触发
BaseCheckpointSaver.put()（可选持久化）
```
