# 09 多轮会话管理

## LangGraph 的会话模型

LangGraph 以 `thread_id` 为会话标识，通过 Checkpointer 实现会话持久化。这是框架的核心特性之一。

---

## 9.1 thread_id 会话模型

```python
# 每个 thread_id 对应一个独立的对话历史
config_alice = {"configurable": {"thread_id": "alice-session-1"}}
config_bob = {"configurable": {"thread_id": "bob-session-1"}}

# Alice 的第一轮
await graph.ainvoke(
    {"messages": [HumanMessage("My name is Alice")]},
    config=config_alice
)

# Bob 的第一轮（完全隔离的状态）
await graph.ainvoke(
    {"messages": [HumanMessage("My name is Bob")]},
    config=config_bob
)

# Alice 的第二轮（自动加载之前的状态）
result = await graph.ainvoke(
    {"messages": [HumanMessage("What's my name?")]},
    config=config_alice
)
# result["messages"][-1].content 会包含 "Alice"
```

---

## 9.2 Checkpoint 层次结构

```
thread_id: "alice-session-1"
    │
    ├── checkpoint_id: "a1b2c3" (超步 3 的状态)
    │   ├── messages: [human_msg, ai_msg, human_msg, ai_msg, ...]
    │   ├── next: ("agent",)
    │   └── metadata: {step: 3, source: "loop"}
    │
    ├── checkpoint_id: "d4e5f6" (超步 2 的状态)
    │   └── ...（历史状态，可用于回溯）
    │
    └── checkpoint_id: "g7h8i9" (超步 1 的状态)
        └── ...
```

**历史访问（时间旅行）:**
```python
# 列出所有检查点
history = list(graph.get_state_history(config))
for h in history:
    print(h.metadata["step"], h.values["messages"][-1].content)

# 从特定检查点恢复
old_config = {"configurable": {"thread_id": "...", "checkpoint_id": "a1b2c3"}}
graph.update_state(old_config, new_values)
await graph.ainvoke(None, config=old_config)
```

---

## 9.3 子图的 Checkpoint 命名空间

```
父图 thread_id: "main-thread"
    ├── 父图 checkpoint: {step: 2}
    │
    └── 子图 namespace: "subgraph:research"
        └── 子图 checkpoint: {step: 5}
```

子图的检查点存储在父图的命名空间下，通过 `checkpoint_ns` 字段区分。

## 9.4 与其他项目的会话管理对比

| 维度 | LangGraph | deer-flow | hermes-agent | nanobot | gstack |
|------|---------|-----------|--------------|---------|--------|
| **会话标识** | thread_id (UUID) | thread_id (UUID) | session_id | 文件名 | PPID |
| **持久化机制** | Checkpointer（序列化状态） | LangGraph Checkpointer | SQLite WAL | JSON 文件 | git WIP commits |
| **存储后端** | PostgreSQL / 内存 | PostgreSQL / 内存 | SQLite | 本地文件系统 | Git 对象存储 |
| **断点恢复** | ✅ 自动 | ✅ 自动 | ✅ 自动 | ❌ | ✅ /context-restore |
| **时间旅行** | ✅ (checkpoint 历史) | ✅ (LangGraph 继承) | ❌ | ❌ | ❌ |
| **并发会话** | ✅ 任意并发 | ✅ | ✅ | ✅ | ✅ (Conductor) |
| **会话搜索** | ❌ (只能按 thread_id) | ❌ | ✅ (FTS5) | ❌ | ❌ |
| **跨线程记忆** | ✅ (BaseStore) | ✅ (MEMORY.md) | ✅ (facts DB) | ❌ | ✅ (learnings.jsonl) |

## 9.5 配置结构

```python
# 完整的 config 结构
config = {
    "configurable": {
        # 必须：会话标识
        "thread_id": "user-123-session-1",

        # 可选：从特定 checkpoint 恢复
        "checkpoint_id": "a1b2c3d4",

        # 可选：子图命名空间（内部使用）
        "checkpoint_ns": "subgraph:research",

        # 自定义：任意用户数据（可在节点中访问）
        "user_id": "user-123",
        "org_id": "org-456",
    },
    "callbacks": [...],   # 回调函数（用于追踪）
    "metadata": {...},    # 元数据（用于过滤/查询）
    "tags": ["production"],
    "context": MyContext(user_id="u123"),  # Runtime Context
}
```

## 9.6 PostgreSQL 会话管理

```python
from langgraph.checkpoint.postgres import PostgresSaver

# 生产配置
checkpointer = PostgresSaver.from_conn_string(
    "postgresql://user:pass@localhost/langgraph",
    pool_size=10,
    max_overflow=20,
)

# 初始化表结构（只需运行一次）
await checkpointer.setup()

# 清理旧会话（定期维护）
# 没有内置清理 API，需要直接 SQL：
# DELETE FROM checkpoints WHERE thread_id = '...' AND step < N
```

**表结构（PostgresSaver）:**
```sql
CREATE TABLE checkpoints (
    thread_id TEXT NOT NULL,
    checkpoint_ns TEXT NOT NULL DEFAULT '',
    checkpoint_id TEXT NOT NULL,
    parent_checkpoint_id TEXT,
    type TEXT,
    checkpoint JSONB NOT NULL,
    metadata JSONB NOT NULL DEFAULT '{}',
    PRIMARY KEY (thread_id, checkpoint_ns, checkpoint_id)
);

CREATE TABLE checkpoint_writes (
    thread_id TEXT NOT NULL,
    checkpoint_ns TEXT NOT NULL DEFAULT '',
    checkpoint_id TEXT NOT NULL,
    task_id TEXT NOT NULL,
    idx INTEGER NOT NULL,
    channel TEXT NOT NULL,
    type TEXT,
    blob BYTEA,
    PRIMARY KEY (thread_id, checkpoint_ns, checkpoint_id, task_id, idx)
);
```
