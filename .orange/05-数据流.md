# 05 数据流

## 5.1 图构建流

```
用户代码
    │
    ▼
StateGraph(State)                     # 声明状态结构（TypedDict）
    │
    ├── add_node("agent", agent_fn)   # 注册节点
    ├── add_node("tools", ToolNode)
    ├── add_edge(START, "agent")
    ├── add_conditional_edges(...)
    └── compile(checkpointer=...)
           │
           ▼
CompiledStateGraph (inherits Pregel)
    ├── nodes: {"agent": PregelNode, "tools": PregelNode}
    ├── channels: {"messages": BinaryOperatorAggregate, ...}
    ├── checkpointer: InMemorySaver
    └── 图结构验证（检测孤立节点、无效边）
```

## 5.2 执行流（invoke/ainvoke）

```
graph.ainvoke({"messages": [user_msg]}, config={"configurable": {"thread_id": "t1"}})
    │
    ▼
Pregel.ainvoke()
    │
    ▼
AsyncPregelLoop.initialize()
    ├── 从 checkpointer 加载 thread_id="t1" 的状态（如有）
    ├── 将输入写入对应 Channel
    └── 设置初始 versions_seen

    │
    ▼ 超步循环:
┌──────────────────────────────────────────────────────┐
│ AsyncPregelLoop.tick()                               │
│                                                      │
│   1. 扫描 Channels 的版本                             │
│   2. 与 versions_seen 对比，确定哪些节点有新输入      │
│   3. 检查 interrupt_before → 如有中断点，抛出 Interrupt│
│   4. 构建 tasks = [PregelTask(node="agent", input=...)]│
│   5. 并行执行所有 tasks                               │
│      ├── 调用 agent_fn(state)                        │
│      └── 返回 {"messages": [ai_msg]}                 │
│   6. Channel.update({"messages": [ai_msg]})          │
│      → BinaryOperatorAggregate: messages += [ai_msg] │
│   7. Checkpointer.put(checkpoint)                    │
│      → 保存当前状态到 thread_id="t1"                  │
│   8. 检查 interrupt_after                            │
│   9. 返回 True（继续）或 False（结束）                 │
└──────────────────────────────────────────────────────┘
    │
    ▼ 直到 tick() 返回 False
返回最终状态
```

## 5.3 流式输出流（astream）

```
graph.astream(input, config=config, stream_mode="messages")
    │
    ▼
GraphRunStream (调用方驱动的异步生成器)
    │
    ▼ 每次 async for 拉取:

超步 N 执行中...
    ├── 节点 "agent" 开始执行
    │   ├── LLM 开始生成 token
    │   ├── yield AIMessageChunk("Hello")   ← stream_mode="messages"
    │   ├── yield AIMessageChunk(" world")
    │   └── yield AIMessageChunk("!")
    │
    ├── 节点产生工具调用
    │   └── yield AIMessage(tool_calls=[...])
    │
    ├── 节点 "tools" 执行
    │   └── yield ToolMessage(content="...")
    │
    └── 超步结束
        └── yield StateSnapshot(...)        ← stream_mode="values"（如果选择）
```

**stream_mode 选择逻辑:**
```python
# 可以同时选多个 mode
async for chunk in graph.astream(
    input,
    stream_mode=["messages", "updates"]
):
    event_type, data = chunk
    if event_type == "messages":
        # AIMessageChunk 或 ToolMessage
    elif event_type == "updates":
        # {"agent": {"messages": [...]}}
```

## 5.4 Human-in-the-Loop 数据流

```
第一次执行（到达中断点）:
    graph.ainvoke(input, config=config)
         ↓
    超步执行...
         ↓
    触发 interrupt_before=["review_node"]
         ↓
    保存 Checkpoint（包含 pending_sends）
         ↓
    抛出 GraphInterrupt

人类查看和修改:
    state = graph.get_state(config)
    # state.next = ("review_node",)
    # state.values = {"messages": [...]}

    graph.update_state(config, {"messages": [human_feedback]})
    # 写入 Checkpoint，追加 human_feedback

继续执行:
    graph.ainvoke(None, config=config)
    # None 表示"从当前 Checkpoint 继续"
    # 从 review_node 开始执行
```

## 5.5 Send API 数据流（动态并行）

```
coordinator 节点返回:
    return [
        Send("worker", {"task": "task_1"}),
        Send("worker", {"task": "task_2"}),
        Send("worker", {"task": "task_3"}),
    ]
         ↓
PregelLoop 解析 Send 列表
         ↓
超步 N+1:
    ├── 并行执行 worker({"task": "task_1"})
    ├── 并行执行 worker({"task": "task_2"})
    └── 并行执行 worker({"task": "task_3"})
         ↓
所有结果通过 BinaryOperatorAggregate Channel 聚合
```

## 5.6 子图数据流

```
父图状态: {"parent_messages": [...], "result": None}
         ↓
父图节点 "subagent" 被触发
         ↓
subgraph.invoke({"sub_messages": [...]})
    ├── 子图有自己独立的 State 类型
    ├── 子图有自己独立的 Channels
    └── 子图有自己的 Checkpoint namespace（如 checkpointer）
         ↓
子图返回 {"sub_result": "..."}
         ↓
父图节点接收子图输出
父图 Channel 更新: {"result": "sub_result"}
```
