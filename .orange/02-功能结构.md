# 02 功能结构

## 核心功能模块

### 2.1 图构建 API

**StateGraph**: 用户面向的图构建 API

```python
from langgraph.graph import StateGraph, END

class State(TypedDict):
    messages: list[dict]
    next: str

builder = StateGraph(State)
builder.add_node("agent", agent_fn)
builder.add_node("tools", ToolNode(tools))
builder.add_edge(START, "agent")
builder.add_conditional_edges("agent", route_fn)
builder.add_edge("tools", "agent")
builder.add_edge("agent", END)

graph = builder.compile(checkpointer=InMemorySaver())
```

**关键 API**:
- `add_node(name, fn)`: 添加节点
- `add_edge(from, to)`: 添加固定边
- `add_conditional_edges(from, route_fn, mapping)`: 添加条件边
- `compile(checkpointer, interrupt_before, interrupt_after)`: 编译图

---

### 2.2 状态管理（Channels）

**Channel 类型**:

| Channel | 行为 | 用途 |
|---------|------|------|
| `LastValue` | 保留最新值（覆盖） | 单值状态字段 |
| `BinaryOperatorAggregate` | 用函数聚合（如 `operator.add`） | 消息列表（追加） |
| `Topic` | 多订阅者发布 | 扇出通信 |
| `EphemeralValue` | 超步后清除 | 临时中间值 |
| `NamedBarrierValue` | 等待所有写入者 | 同步屏障 |

**TypedDict 简写语法**:
```python
from typing import Annotated
from langgraph.graph.message import add_messages

class State(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]  # BinaryOperatorAggregate
    user_id: str  # LastValue（默认）
```

### 2.3 检查点系统（Checkpointer）

**内置实现**:
- `InMemorySaver`: 内存（开发/测试）
- `PostgresSaver`: PostgreSQL（生产）
- `ShallowPostgresSaver`: PostgreSQL 浅存储（只保留最近检查点）

**用法**:
```python
from langgraph.checkpoint.memory import InMemorySaver

graph = builder.compile(checkpointer=InMemorySaver())

# 执行（带 thread_id 实现持久化）
config = {"configurable": {"thread_id": "user-123"}}
result = await graph.ainvoke({"messages": [...]}, config=config)

# 断点恢复
state = graph.get_state(config)
graph.update_state(config, {"messages": [...]})
await graph.ainvoke(None, config=config)  # 从当前状态继续
```

### 2.4 流式输出（Stream Modes）

```python
async for event in graph.astream(input, config=config, stream_mode="messages"):
    if isinstance(event, AIMessageChunk):
        print(event.content, end="")
```

**7 种 stream_mode**:

| Mode | 内容 | 用途 |
|------|------|------|
| `values` | 每个超步后的完整状态 | 观察状态变化 |
| `updates` | 每个节点的增量更新 | 细粒度观察 |
| `messages` | 流式 token（`AIMessageChunk`） | 实时打字效果 |
| `custom` | 节点显式发送的数据 | 自定义进度 |
| `checkpoints` | checkpoint 事件 | 调试/审计 |
| `tasks` | 任务级别事件 | 性能分析 |
| `debug` | 所有内部事件 | 深度调试 |

### 2.5 人机交互（Human-in-the-Loop）

```python
# 编译时声明中断点
graph = builder.compile(
    checkpointer=checkpointer,
    interrupt_before=["review_node"],  # 执行前中断
    interrupt_after=["draft_node"],    # 执行后中断
)

# 运行到中断点
await graph.ainvoke(input, config=config)

# 查看当前状态
state = graph.get_state(config)
print(state.next)  # 下一个要执行的节点

# 注入人类反馈
graph.update_state(config, {"messages": [human_message]})

# 继续执行
await graph.ainvoke(None, config=config)
```

### 2.6 多 Agent 支持

**子图嵌套**:
```python
subgraph = subgraph_builder.compile()
parent_builder.add_node("subagent", subgraph)
```

**Send API（动态并行分发）**:
```python
from langgraph.types import Send

def route_to_workers(state):
    return [Send("worker", {"task": task}) for task in state["tasks"]]

builder.add_conditional_edges("coordinator", route_to_workers)
```

### 2.7 长期记忆（BaseStore）

```python
from langgraph.store.postgres import PostgresStore

store = PostgresStore.from_conn_string(conn_str)

async def agent_node(state, config, *, store: BaseStore):
    memories = await store.asearch(
        ("user", config["user_id"], "memories"),
        query="relevant context"
    )
    # 写入记忆
    await store.aput(
        ("user", config["user_id"], "memories"),
        key=str(uuid4()),
        value={"content": "important fact"}
    )
```

**跨 thread 共享**，与 Checkpointer（单 thread 内）互补。

### 2.8 Runtime Context（只读依赖注入）

```python
from langgraph.types import Runtime

def agent_node(state: State, *, runtime: Runtime[MyContext]):
    user_id = runtime.context.user_id  # 只读
```

编译时通过 `context_schema=MyContext` 声明，运行时通过 `config["context"]` 注入，节点无法修改 context（只读约束）。
