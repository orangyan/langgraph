# 01 产品介绍

## 项目背景

LangGraph 是 LangChain 公司（前 LangChain AI）于 2024 年初发布的 Agent 编排框架。它从 LangChain 的失败中吸取教训：原有的 `AgentExecutor` + `Chain` 架构过于简单，无法处理复杂的多步骤、有状态、需要人机交互的 Agent 工作流。

## 核心定位

**LangGraph = 有状态的 Agent 工作流引擎**

```
AgentExecutor (旧，已废弃)     LangGraph (新)
    简单的 while 循环           有向图 + Pregel 执行引擎
    无状态                      有状态（Channels）
    无断点恢复                  Checkpointer 持久化
    无并行                      Send API 动态并行
    无人机交互                  interrupt_before/after
    无子图                      子图嵌套
```

## 与 LangChain 的关系

```
langchain-core        基础抽象（BaseTool, BaseLanguageModel, Runnable）
       ↑
langchain / langchain_v1   高级封装（create_agent, AgentMiddleware）
       ↑
langgraph             图执行引擎（StateGraph, Pregel, Checkpointer）
```

LangGraph 是**独立的包**（`langgraph`），不依赖 LangChain，但 `langchain_v1` 的 `create_agent` 内部使用 LangGraph 实现。

## 目标用户

- **AI 应用开发者**: 构建复杂的多步骤 Agent 工作流
- **研究者**: 实验各种 Agent 架构（ReAct、Plan-Execute、Reflection）
- **企业用户**: 通过 LangGraph Platform 部署生产级 Agent

## 开源信息

- **仓库**: `langchain-ai/langgraph`
- **语言**: Python（主要）+ TypeScript（JS 版本独立维护）
- **许可**: MIT
- **版本**: 0.3.x（2026 年）
